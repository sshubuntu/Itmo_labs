# Лабораторная работа №6 - Численное решение ОДУ

## Вариант 18

### Описание
Программа для численного решения обыкновенных дифференциальных уравнений (ОДУ) методами:
1. **Метод Эйлера** (одношаговый метод 1-го порядка точности)
2. **Метод Рунге-Кутта 4-го порядка** (одношаговый метод 4-го порядка точности)
3. **Метод Милна** (многошаговый метод предиктор-корректор 4-го порядка точности)

### Требования
- Python 3.7+
- tkinter (обычно входит в стандартную установку Python)
- matplotlib
- numpy

### Функциональность

#### Доступные уравнения:
1. `y' = x + y` - с точным решением
2. `y' = y - x²` - с точным решением
3. `y' = x² + y²` - без аналитического решения

#### Входные параметры:
- **x₀** - начальное значение x
- **y₀** - начальное значение y (начальное условие)
- **xₙ** - конечное значение x
- **h** - шаг интегрирования
- **ε** - точность для метода Милна

#### Валидация входных данных:
✓ Проверка корректности числовых значений  
✓ Проверка что xₙ > x₀  
✓ Проверка что h > 0  
✓ Проверка что h < (xₙ - x₀)  
✓ Проверка что ε > 0  
✓ Проверка выбора хотя бы одного метода  
✓ Проверка выбора уравнения  

#### Результаты:
- **Таблица** с приближенными значениями для всех выбранных методов
- **График** сравнения точного и приближенных решений
- **Оценка погрешности**:
  - Для одношаговых методов (Эйлер, Рунге-Кутта) - по правилу Рунге
  - Для метода Милна - сравнение с точным решением (если доступно)

### Математические формулы

#### Метод Эйлера:
```
yᵢ₊₁ = yᵢ + h·f(xᵢ, yᵢ)
```
Порядок точности: O(h)

#### Метод Рунге-Кутта 4-го порядка:
```
k₁ = h·f(xᵢ, yᵢ)
k₂ = h·f(xᵢ + h/2, yᵢ + k₁/2)
k₃ = h·f(xᵢ + h/2, yᵢ + k₂/2)
k₄ = h·f(xᵢ + h, yᵢ + k₃)
yᵢ₊₁ = yᵢ + (k₁ + 2k₂ + 2k₃ + k₄)/6
```
Порядок точности: O(h⁴)

#### Метод Милна:
**Прогноз:**
```
yᵢ(прогн) = yᵢ₋₄ + (4h/3)·(2fᵢ₋₁ - fᵢ₋₂ + 2fᵢ₋₃)
```

**Коррекция:**
```
yᵢ(корр) = yᵢ₋₂ + (h/3)·(fᵢ(прогн) + 4fᵢ₋₁ + fᵢ₋₂)
```
Порядок точности: O(h⁴)

*Примечание:* Для запуска метода Милна первые 3 точки вычисляются методом Рунге-Кутта.

#### Правило Рунге:
```
R = |yₕ - yₕ/₂| / (2ᵖ - 1)
```
где p - порядок точности метода

### Примеры использования

#### Пример 1: y' = x + y
- x₀ = 0
- y₀ = 1
- xₙ = 1
- h = 0.1
- ε = 0.001

Точное решение: `y = 2eˣ - x - 1`

#### Пример 2: y' = y - x²
- x₀ = 0
- y₀ = 2
- xₙ = 1
- h = 0.1
- ε = 0.001

Точное решение: `y = x² + 2x + 2`
